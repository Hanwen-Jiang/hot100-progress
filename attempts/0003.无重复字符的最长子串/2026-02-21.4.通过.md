## 代码

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        HashMap<Character, Integer> smap = new HashMap<>();
        int len = 0, llen = 0, breakpoint = 0;
        for(int i=0; i<s.length(); i++) {
            char c = s.charAt(i);
            if(smap.containsKey(c) && breakpoint <= smap.get(c)) {
                int k = smap.get(c);
                breakpoint = k;
                len = i-k;
            } else {
                len++;
            }
            smap.put(c, i);
            llen = len > llen ? len : llen;
        }
        return llen;
    }
}
```
