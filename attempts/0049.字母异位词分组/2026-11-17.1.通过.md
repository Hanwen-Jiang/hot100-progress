## 代码

```python
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        s = {}
        for x in strs:
            k = [0]*26
            for i in x:
                k[ord(i)-ord('a')]+=1
            if tuple(k) in s:
                s[tuple(k)].append(x)
            else:
                s[tuple(k)]=[x]
        return [s[x] for x in s]
```
