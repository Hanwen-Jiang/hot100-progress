## 代码

```python
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        s = defaultdict(list)
        for x in strs:
            k = [0]*26
            for i in x:
                k[ord(i)-ord('a')]+=1
            s[tuple(k)].append(x)
        return [s[x] for x in s]
```
