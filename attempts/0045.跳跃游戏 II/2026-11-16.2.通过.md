## 代码

```python
class Solution:
    def jump(self, nums: list[int]) -> int:
        far, ind, s = 0, 0, 0
        while ind <= far and far < len(nums)-1:
            lf = far
            far = max(ind+k+a for k, a in enumerate(nums[ind:far+1]))
            ind = lf+1
            s+=1
        return s
```
