## 错在哪里

结果正确但会超时：写成了完整的快速排序（左右两边都递归），pivot 固定取最右边。有序数组或全相同的数组每次只分出一个元素，退化成 O(n²)，递归深度也是 O(n)。

## 怎么发现的

本地 10 万规模的有序数组、全相同数组直接 RecursionError；小规模随机数据答案都对。

## 差在哪一步

差在三步：只进答案所在的一边（快速选择，平均 O(n)）；随机选 pivot，避免有序输入退化；三路划分，把等于 pivot 的元素单独放一组，处理大量重复元素。

## 代码

```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        def quickSort(nums, left=0, right=None):
            if left >= right:
                return nums[len(nums) - k]
            pivot, i = nums[right], left
            for j in range(left, right):
                if pivot > nums[j]:
                    nums[i], nums[j] = nums[j], nums[i]
                    i += 1
            nums[i], nums[right] = nums[right], nums[i]
            if i == len(nums) - k:
                return nums[i]
            quickSort(nums, left, i-1)
            quickSort(nums, i+1, right)
            return nums[len(nums) - k]
        return quickSort(nums, 0, len(nums) - 1)
```
