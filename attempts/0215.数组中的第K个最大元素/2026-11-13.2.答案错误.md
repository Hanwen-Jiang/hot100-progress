## 错在哪里

两处：两个递归调用前少了 return，递归结果被扔掉，永远返回第一层的 pivot；len(left) > k 应为 >=，left 恰好有 k 个元素时第 k 大就在 left 里。

## 怎么发现的

随机测试 3000 组错 2403 组。

## 差在哪一步

思路（随机 pivot + 三路划分，只进答案所在的一边）已经对了，差在递归要把结果 return 回来，以及边界 len(left) >= k。

## 代码

```python
import random
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        pivot = random.choice(nums)
        left = [x for x in nums if x > pivot]
        right = [x for x in nums if x < pivot]
        if len(left) > k:
            self.findKthLargest(left, k)
        elif len(right) > len(nums) - k:
            self.findKthLargest(right, k+len(right)-len(nums))
        return pivot
```
