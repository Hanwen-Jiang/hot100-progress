## 代码

```java
class Solution {
    public int maxSubArray(int[] nums) {
        // -2 1 -3 4 -1 2 1 -5 4
        // -2 1 -2 4 3 5 6 1 5
        int max = Integer.MIN_VALUE, lastMax = 0;
        for (int n:nums){
            lastMax = Math.max(lastMax+n, n);
            if(max < lastMax) max=lastMax;
        }
        return max;
    }

    static void main() {
        Solution solution = new Solution();
        System.out.println(solution.maxSubArray(new int[]{-2, 1, -3, 4, -1, 2, 1, -5, 4}));
    }
}
```
