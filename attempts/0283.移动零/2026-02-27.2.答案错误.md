## 代码

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int len = nums.length, index = 0;
        int[] res = new int[len];
        for (int num : nums) if (num != 0) res[index++] = num;
        nums = res;
    }

    static void main() {
        Solution solution = new Solution();
        solution.moveZeroes(new int[]{0,1,0,3,12});
    }
}
```
