## 代码

```java
class Solution {
    public boolean hasCycle(ListNode head) {
        HashSet<Integer> set = new HashSet<>();
        while (head != null) {
            if (set.contains(System.identityHashCode(head))) return true;
            set.add(System.identityHashCode(head));
            head = head.next;
        }
        return false;
    }
}
```
