## 代码

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        HashMap<Integer, Integer> tmap = new HashMap<>();
        for(int i = 0; i < nums.length; i++) {
            int v = nums[i];
            int tv = target - v;
            if (tmap.containsKey(tv)) return new int[] {tmap.get(tv), i};
            tmap.put(v, i);
        }
        return null;
    }
}
```
