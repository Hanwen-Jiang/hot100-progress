## 代码

```java
class Solution {
    int ans = 0;
    int depth(TreeNode root) {
        if (root == null) return 0;
        int left = depth(root.left), right = depth(root.right);
        ans = Math.max(left+right, ans);
        return Math.max(left, right) + 1;
    }
    public int diameterOfBinaryTree(TreeNode root) {
        ans = 0;
        depth(root);
        return ans;
    }
}
```
