## 代码

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int all = 1, zeroNum = -1;
        for (int i=0; i < nums.length; i++) {
            int n = nums[i];
            if (n==0 && zeroNum == -1) zeroNum = i;
            else if (n==0) return new int[nums.length];
            else all *= n;
        }
        if (zeroNum != -1) {
            nums = new int[nums.length];
            nums[zeroNum] = all;
        } else for (int i=0; i < nums.length; i++) nums[i] = (int)all/nums[i];
        return nums;
    }
}
```
