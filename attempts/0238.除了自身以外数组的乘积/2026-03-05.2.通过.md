## 代码

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int len=nums.length, right=1;
        int[] left = new int[len], answer = new int[len];
        left[0]=1;
        for(int i=1;i<len;i++) left[i] = left[i-1] * nums[i-1];
        for(int i=len-1; i>=0; i--) {
            answer[i] = right*left[i];
            right *= nums[i];
        }
        return answer;
    }
}
```
