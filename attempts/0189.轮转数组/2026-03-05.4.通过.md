## 代码

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        if (n <= 1) return;
        k %= n;
        if (k == 0) return;
        int[] res = new int[n];
        int split = n - k;
        System.arraycopy(nums, split, res, 0, k);
        System.arraycopy(nums, 0, res, k, split);
        System.arraycopy(res, 0, nums, 0, n);
    }
}
```
