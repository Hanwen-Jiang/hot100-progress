## 代码

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0, head), p = dummy, last = dummy;
        while (p.next != null && p.next.next != null) {
            ListNode first = p.next;
            ListNode second = p.next.next;
            first.next = second.next;
            second.next = first;
            p.next = second;
            p = first;
        }
        return dummy.next;
    }
}
```
