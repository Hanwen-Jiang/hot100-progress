## 代码

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        def gen(s, l, r):
            if not r:
                yield s
            if l:
                yield from gen(s+'(', l-1, r)
            if r>l:
                yield from gen(s+')', l, r-1)
        return list(gen('', n, n))
```
