## 代码

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        def gen(s, l, r):
            if not r and not l:
                yield s
            if l:
                yield from gen(s+'(', l-1, r+1)
            if r:
                yield from gen(s+')', l, r-1)
        return list(gen('', n, 0))
```
