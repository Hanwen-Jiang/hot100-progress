## 代码

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        path, res = '', []
        def dfs(op, cl):
            nonlocal path
            if len(path) == 2*n:
                res.append(path)
            if op>0:
                path+='('
                dfs(op-1, cl+1)
                path=path[:-1]
            if cl>0:
                path+=')'
                dfs(op, cl-1)
                path=path[:-1]
        dfs(n, 0)
        return res
```
