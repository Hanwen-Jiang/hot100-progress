## 错在哪里

改成左右两个指针往中间走，想让分界点不再固定在中间。但循环条件 low+ind < l 混用了「最低价的下标」和「步数」，两个指针会交叉，最后选出来的卖出日可能在买入日之前，相当于先卖后买。

## 怎么发现的

最小反例 [2,2,1,1]：答案是 0，返回 1。最后 low = 2（价格 1）、high = 1（价格 2），卖出日在买入日前面。

## 差在哪一步

两头分别找极值，始终没法保证「卖出在买入之后」这个顺序。只从左往右扫一遍，在每个卖出日只看它左边的最低价，顺序就天然成立了。

## 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        lowtag, hightag = inf, -inf
        low, high = 0, len(prices)-1
        l, ind = high, 0
        while low+ind < l:
            if lowtag > prices[ind]:
                lowtag=prices[ind]
                low=ind
            if hightag < prices[l-ind]:
                hightag=prices[l-ind]
                high=l-ind
            ind += 1
        return max(hightag-lowtag, 0)
```
