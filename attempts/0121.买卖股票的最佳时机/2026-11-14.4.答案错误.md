## 错在哪里

加上了下标约束（ind < high、l-ind > low），并按差值增量地调整利润。但整个过程只维护一对 (low, high)：一旦把买入点挪到后面一个更低的价格，前面那些「早买早卖」的组合就再也回不来了。

## 怎么发现的

最小反例 [2,3,1,1]：第 0 天买、第 1 天卖赚 1；但买入点被挪到第 2 天（价格 1）后，后面没有更高的价格，前面的 3 又因为 l-ind > low 被挡掉，返回 0。随机 3000 组错 166 组。

## 差在哪一步

最优的一对不一定由「全局最低」或「全局最高」组成。要保留的不是一对点，而是对每个卖出日都成立的信息：到今天为止的最低价。

## 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if len(prices) <= 1:
            return 0
        lowtag, hightag = prices[0], prices[-1]
        low, high = 0, len(prices)-1
        l= high
        profit = prices[-1]-prices[0]
        for ind in range(len(prices)):
            a, b = lowtag-prices[ind], prices[l-ind]-hightag
            if a > 0 and ind < high:
                lowtag = prices[ind]
                low = ind
                profit += a
            if b > 0 and l-ind > low:
                hightag = prices[l-ind]
                high = l-ind
                profit += b
        return max(profit, 0)
```
