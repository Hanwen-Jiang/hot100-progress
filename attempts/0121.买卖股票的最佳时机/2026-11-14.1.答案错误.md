## 错在哪里

把数组从中间劈开：前一半找最低价当买入，后一半找最高价当卖出。两处问题：没有和 0 取 max，价格一路下跌时会返回负数；更根本的是默认买入一定在前一半、卖出一定在后一半，最优的一对完全可能都在同一半里。

## 怎么发现的

两个示例都能过。最小反例 [2,1]：返回 -1，答案是 0。

## 差在哪一步

不该分别找「最低点」和「最高点」再拼起来。正确的切入点是：固定卖出日 j，最好的买入价就是 j 之前的最低价，一边扫一边记前缀最小值。

## 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        lowtag, hightag = inf, -inf
        low, high = 0, len(prices)-1
        l=high
        for ind in range((len(prices)+1)//2):
            if lowtag > prices[ind]:
                lowtag=prices[ind]
                low=ind
            if hightag < prices[l-ind]:
                hightag=prices[l-ind]
                high=l-ind
        return hightag-lowtag
```
