## 说明

一次遍历：mintag 是到今天为止的最低价，假设今天卖出，利润就是 p - mintag，取所有天里的最大值。O(n) 时间、O(1) 空间。

## 回顾

前四次都在「分别找最低点和最高点，再想办法保证先买后卖」这个框架里打补丁：先劈两半，再双指针，再加下标约束。四版都能过两个示例，但在长度不超过 4 的小数组上都能找到反例。转折点是换个问法：不问「哪天买、哪天卖」，而问「如果今天卖，最好是哪天买的」，答案就是前缀最小值。

## 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        mintag, profit = inf, 0
        for p in prices:
            mintag = min(p, mintag)
            profit = max(p-mintag, profit)
        return profit
```
