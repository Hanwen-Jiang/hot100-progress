## 错在哪里

补上了 max(..., 0)，负数问题没了，但「买在前一半、卖在后一半」的假设没动。

## 怎么发现的

最小反例 [1,2,1,1]：第 0 天买、第 1 天卖赚 1，两天都在前一半；后一半最高价是 1，返回 0。

## 差在哪一步

同第 1 次：问题出在把数组劈成两半这个框架本身，不是边界细节。

## 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        lowtag, hightag = inf, -inf
        low, high = 0, len(prices)-1
        l, mid=high, (len(prices)+1)//2
        for ind in range(mid):
            if lowtag > prices[ind]:
                lowtag=prices[ind]
                low=ind
            if hightag < prices[l-ind]:
                hightag=prices[l-ind]
                high=l-ind
        return max(hightag-lowtag, 0)
```
