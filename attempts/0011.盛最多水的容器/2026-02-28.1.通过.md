## 代码

```java
class Solution {
    public int maxArea(int[] height) {
        int len = height.length, left = 0, right = len-1, maxArea = 0;
        while (left < right) {
            int h = Math.min(height[left], height[right]),w = right - left;
            maxArea = Math.max(h*w, maxArea);
            if (h == height[left]) left++;
            else right--;
        }
        return maxArea;
    }
}
```
