## 代码

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        int ans = 0, pre = 0;
        HashMap<Integer, Integer> map = new HashMap<>((nums.length + 1) * 2);
        map.put(0, 1);
        for (int v : nums) {
            pre += v;
            Integer hit = map.get(pre - k);
            if (hit != null) ans += hit;
            Integer cnt = map.get(pre);
            if (cnt == null) map.put(pre, 1);
            else map.put(pre, cnt + 1);
        }
        return ans;
    }
}
```
