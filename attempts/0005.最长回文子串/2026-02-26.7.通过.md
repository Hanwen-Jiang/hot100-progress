## 代码

```java
class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }

        int n = s.length();
        boolean[] dp = new boolean[n];
        
        int start = 0;
        int maxLen = 1;

        for (int i = n - 1; i >= 0; i--) {
            for (int j = n - 1; j >= i; j--) {
                if (s.charAt(i) == s.charAt(j) && (j - i < 3 || dp[j - 1])) {
                    dp[j] = true;
                    if (j - i + 1 > maxLen) {
                        maxLen = j - i + 1;
                        start = i;
                    }
                } else {
                    dp[j] = false;
                }
            }
        }
        
        return s.substring(start, start + maxLen);
    }
}
```
