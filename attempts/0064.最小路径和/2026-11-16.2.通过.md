## 代码

```python
class Solution:
    def minPathSum(self, grid: list[list[int]]) -> int:
        prev = [0] * len(grid[0])
        for i, ilist in enumerate(grid):
            cur = []
            for j, y in enumerate(ilist):
                cur.append(min(prev[j] if i>0 else inf, cur[j-1] if j>0 else inf, 0 if i==0 and j==0 else inf)+y)
            prev = cur
        return prev[-1]
```
