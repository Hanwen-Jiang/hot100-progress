## 代码

```python
class Solution:
    def minPathSum(self, grid: list[list[int]]) -> int:
        prev = [0] + [inf] * (len(grid[0])-1)
        for i, ilist in enumerate(grid):
            cur = []
            for j, y in enumerate(ilist):
                cur.append(min(prev[j], cur[j-1] if j>0 else inf)+y)
            prev = cur
            print(prev)
        return prev[-1]
```
