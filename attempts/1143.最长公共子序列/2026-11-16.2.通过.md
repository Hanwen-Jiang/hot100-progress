## 代码

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        prev = [0] * (len(text2)+1)
        for char1 in text1:
            cur = [0]
            for j, char2 in enumerate(text2):
                cur.append(prev[j]+1 if char1==char2 else max(cur[j], prev[j+1]))
            prev = cur
        return prev[-1]
```
