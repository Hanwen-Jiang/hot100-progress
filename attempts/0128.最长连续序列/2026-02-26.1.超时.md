## 代码

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        HashSet<Integer> set = new HashSet<>();
        for (int num : nums) set.add(num);
        int max = 0;
        while (!set.isEmpty()) {
            int min = Collections.min(set);
            int i = 1;
            set.remove(min);
            while (set.contains(min+1)) {
                set.remove(++min);
                i++;
            }
            max = Math.max(max, i);
        }
        return max;
    }
}
```
