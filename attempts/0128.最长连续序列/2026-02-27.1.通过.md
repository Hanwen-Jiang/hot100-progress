## 代码

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        HashSet<Integer> set = new HashSet<>();
        for (int num : nums) set.add(num);
        int max = 0;
        for (int min: set) {
            if (!set.contains(min-1)) {
                int i = 1;
                while (set.contains(++min)) i++;
                max = Math.max(max, i);
            }
        }
        return max;
    }
}
```
