## 代码

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode cur = head;
        head = new ListNode(0, cur);
        while (cur.next != null) {
            ListNode temp = cur.next;
            cur.next = temp.next;
            temp.next = head.next;
            head.next = temp;
        }
        return head.next;
    }
}
```
