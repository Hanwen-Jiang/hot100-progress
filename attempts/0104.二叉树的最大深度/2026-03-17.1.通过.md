## 代码

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        List<TreeNode> nodes = new ArrayList<>();
        int deep = 1;
        nodes.add(root);
        while (true) {
            List<TreeNode> nodes_temp = new ArrayList<>();
            while (!nodes.isEmpty()) {
                TreeNode treeNode = nodes.getFirst();
                nodes.removeFirst();
                if (treeNode.left != null) nodes_temp.add(treeNode.left);
                if (treeNode.right != null) nodes_temp.add(treeNode.right);
            }
            if (nodes_temp.isEmpty()) return deep;
            nodes = nodes_temp;
            deep++;
        }
    }
}
```
