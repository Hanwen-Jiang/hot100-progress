## 代码

```java
class Solution {
    public ListNode detectCycle(ListNode head) {
        if (head == null || head.next == null) return null;
        HashSet<Integer> set = new HashSet<>();
        while (head != null) {
            if (!set.add(System.identityHashCode(head))) return head;
            head = head.next;
        }
        return null;
    }
}
```
