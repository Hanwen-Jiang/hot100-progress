## 代码

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        dp = [0] * (len(nums)+2)
        for i, n in enumerate(nums):
            dp[i+2] = max(dp[i]+n, dp[i+1])
        return dp[-1]
```
