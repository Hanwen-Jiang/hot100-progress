## 代码

```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        if len(nums) <= 1:
            return [nums[:]]
        return [[x]+y for i, x in enumerate(nums) for y in self.permute(nums[:i]+nums[i+1:])]
```
