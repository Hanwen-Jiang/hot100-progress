## 代码

```python
class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:
        if len(nums) <= 1:
            return [nums[:]]
        return [[x]+p for i, x in enumerate(nums) for p in self.permute(nums[:i]+nums[i+1:])]
```
