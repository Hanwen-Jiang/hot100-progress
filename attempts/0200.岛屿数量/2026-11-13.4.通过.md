## 代码

```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        h, w = len(grid), len(grid[0])
        def sink(x, y):
            if 0 <= x < h and 0 <= y < w and grid[x][y] == '1':
                grid[x][y] = '0'
                for dx, dy in (1, 0), (-1, 0), (0, 1), (0, -1):
                    sink(x+dx, y+dy)
                return 1
            return 0
        return sum(sink(i, j) for i in range(h) for j in range(w))
```
