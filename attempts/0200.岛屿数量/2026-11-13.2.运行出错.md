## 错在哪里

IndexError：边界检查里把行数和列数写反了，写成 x >= w or y >= h，x 是行下标、y 是列下标，应为 x >= h or y >= w。另外用了 cell is '1' 比较字符串，应该用 ==（is 比较的是对象是否同一个，能过只是因为单字符字符串碰巧被缓存）。

## 怎么发现的

只在非正方形网格上暴露：正方形时 h == w，写反了也不出错。比如 [["1"],["1"],["0"]]（3 行 1 列）就会越界。

## 差在哪一步

思路（遇到陆地就 DFS 淹掉整座岛、计数加一）是对的，只差边界条件：行下标对行数，列下标对列数。

## 代码

```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        h, w = len(grid), len(grid[0])
        num = 0
        def delLand(x, y):
            if x < 0 or y < 0 or x >= w or y >= h:
                return
            sea = grid[x][y] == '0'
            if not sea:
                grid[x][y] = '0'
                top, bottom, left, right = (x, y-1), (x, y+1), (x-1, y),(x+1, y)
                delLand(*top)
                delLand(*bottom) 
                delLand(*left) 
                delLand(*right)
        for i, row in enumerate(grid):
            for j, cell in enumerate(row):
                if cell is '1':
                    delLand(i, j)
                    num = num + 1
        return num
```
