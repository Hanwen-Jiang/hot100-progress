## 后续

之后学会了两种写法：简洁递归（sink 淹掉一座岛返回 1、否则返回 0，答案是所有返回值之和）和 BFS，分别在 solutions/python/0200.岛屿数量.简洁递归.py 和 0200.岛屿数量.BFS.py。注意：递归写法在 300×300 的蛇形网格上会超过 Python 默认递归深度（RecursionError），BFS 没有这个问题。

## 代码

```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        h, w = len(grid), len(grid[0])
        num = 0
        def delLand(x, y):
            if x < 0 or y < 0 or x >= h or y >= w:
                return
            sea = grid[x][y] == '0'
            if not sea:
                grid[x][y] = '0'
                top, bottom, left, right = (x-1, y), (x+1, y), (x, y-1), (x, y+1)
                delLand(*top)
                delLand(*bottom)
                delLand(*left)
                delLand(*right)
        for i, row in enumerate(grid):
            for j, cell in enumerate(row):
                if cell is '1':
                    delLand(i, j)
                    num = num + 1
        return num
```
