## 代码

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        dp = [True] + [False] * len(s)
        for i,x in enumerate(dp):
            tis = [j for j,b in enumerate(dp[:i+1]) if b]
            if len([0 for ti in tis if s[ti:i+1] in wordDict]) != 0:
                dp[i]=True
        return not dp[len(s)]
```
