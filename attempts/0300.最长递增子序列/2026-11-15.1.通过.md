## 代码

```python
class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        dp = [1]*len(nums)
        m=0
        for i, num in enumerate(nums):
            maxd = 0
            for j, x in enumerate(nums[:i]):
                if x < num and maxd < dp[j]:
                    maxd=dp[j]
            dp[i]=maxd+1
            m = max(1, m, maxd+1)
        return m
```
