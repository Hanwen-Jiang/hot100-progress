## 代码

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n) {
                int v = nums[i];
                int idx = v - 1;
                if (nums[idx] == v) break;
                int tmp = nums[idx];
                nums[idx] = v;
                nums[i] = tmp;
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
}
```
