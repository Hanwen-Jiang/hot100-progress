## 代码

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        boolean[] seen = new boolean[n + 1];
        for (int x : nums) if (x > 0 && x <= n) seen[x] = true;
        for (int i = 1; i <= n; i++) if (!seen[i]) return i;
        return n + 1;
    }
}
```
