## 代码

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        if (n == 0) return 1;

        for (int i = 0; i < n; i++) {
            int x = nums[i];
            if (x <= 0 || x > n) nums[i] = n + 1;
        }

        for (int i = 0; i < n; i++) {
            int x = nums[i];
            if (x < 0) x = -x;
            if (x >= 1 && x <= n) {
                int idx = x - 1;
                int v = nums[idx];
                if (v > 0) nums[idx] = -v;
            }
        }

        for (int i = 0; i < n; i++) if (nums[i] > 0) return i + 1;
        return n + 1;
    }
}
```
