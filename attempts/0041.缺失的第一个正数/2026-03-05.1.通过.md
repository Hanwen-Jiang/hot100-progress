## 代码

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        HashSet<Integer> set = new HashSet<>();
        for(int n:nums) if(n>0 && n<=nums.length) set.add(n);
        int len = set.size();
        for(int i=1; i<=len+1; i++) if(!set.contains(i)) return i;
        return 1;
    }
}
```
