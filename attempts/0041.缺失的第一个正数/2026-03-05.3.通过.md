## 代码

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int len = nums.length, index = 0;
        boolean[] bmap = new boolean[len+1];
        for(int n:nums) if(n>0 && n<=len && !bmap[n-1]) {bmap[n-1] = true; index++;}
        for(int i=1; i<=index+1; i++) if(!bmap[i-1]) return i;
        return 1;
    }
}
```
