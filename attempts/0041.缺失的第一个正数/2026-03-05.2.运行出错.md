## 代码

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        HashSet<Integer> set = new HashSet<>();
        int len = nums.length, index = 0;
        boolean[] bmap = new boolean[len+1];
        for(int n:nums) if(n>0 && n<=len && !bmap[n]) {bmap[n] = true; index++;}
        
        for(int i=1; i<=index+1; i++) if(!bmap[i]) return i;
        return 1;
    }
}
```
